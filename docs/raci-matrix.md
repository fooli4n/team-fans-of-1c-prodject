# RACI-матрица

**Команда №3 «Фанаты 1с»**
Проект: сервис рекомендаций компьютерных игр

**Обозначения:**
- **R** (Responsible): исполнитель;
- **A** (Accountable): отвечает за результат (утверждает);
- **C** (Consulted): консультирует;
- **I** (Informed): информируется.

## Матрица для сервиса рекомендаций компьютерных игр

## Распределение ответственности при работе с Git (СР2)

Обязанности закреплены на основе RACI-матрицы из СР1. Руководитель разработки: Ивлев Д.А., архитектор: Трубников П.С.

| Обязанность | R (исполнитель) | A (отвечает) |
|---|---|---|
| Создание и настройка репозитория | Ивлев Д.А. (руководитель) | Ивлев Д.А. |
| Поддержка структуры папок и файлов | Все участники, каждый для своих разделов | Ивлев Д.А. |
| Написание отчётов по практическим работам | Все участники согласно своим ролям | Ивлев Д.А. |
| Внесение коммитов с осмысленными сообщениями | Каждый участник за свои изменения | Ивлев Д.А. |
| Проверка Pull Request | Ивлев Д.А. или Трубников П.С. (архитектор) | Ивлев Д.А. |
| Слияние веток (merge) | Ивлев Д.А. | Ивлев Д.А. |
| Резервное копирование и поддержание актуальности | Все участники | Ивлев Д.А. |

### Привязка к ролям

- **Ивлев Д.А. (руководитель разработки):** создаёт и настраивает репозиторий, отвечает за порядок в нём, проверяет Pull Request и выполняет слияние веток.
- **Трубников П.С. (архитектор):** следит за структурой репозитория, проверяет Pull Request вместе с руководителем.
- **Демченко А.И. (программист):** ведёт исходный код в папках `src/`, делает осмысленные коммиты.
- **Анисимов В.С. (исследователь и специалист по данным):** оформляет документацию, материалы по данным и метрикам в своих разделах.
- **Крашенинникова Е.А. (тестировщик):** оформляет отчёты по тестированию и проверяет, что результаты работ в репозитории актуальны.
